A simple file upload web app with an EJS UI (no CSS).

## Features:

- Upload files from a web UI built with EJS.
  -Server-side file handling with configurable upload directory and size limit.
- Simple file listing and download endpoints.
- Basic validation for allowed file types / size.

## Tech stack:

- Node.js (Express)
- JavaScript
- EJS (views)
- multer (or similar middleware) for file handling — adjust to the actual middleware used in the repo
